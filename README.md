# Menu Music Volume

A simple Geode mod that adds a separate volume slider for menu music in Geometry Dash.

  <img width="512" height="512" alt="Menu Music Volume" src="https://github.com/user-attachments/assets/e8be746d-ee83-40f3-961a-2455d5cfcdd7" />
</p>

## Features

* Separate menu music volume
* Volume is saved between sessions
* Custom vertical volume slider
* Works independently from in-game music volume

## Installation

Install **Menu Music Volume** through the Geode mod downloader.

You can also install the `.geode` file manually by placing it in your Geode mods folder.

## Requirements

* Geometry Dash 2.2081
* Geode

## Building

If you want to build the mod from source, make sure you have the Geode CLI set up, then run:

```sh
geode build
```

For more information, see the [Geode SDK documentation](https://docs.geode-sdk.org/getting-started/create-mod#build).
